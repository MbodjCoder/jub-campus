# Logos partenaires JUB Campus

Dépose ici les logos officiels des partenaires (format conseillé : **SVG** ou **PNG transparent**, ratio carré, ≥ 256×256 px).

Le composant `BandeauLogos` cherche automatiquement chaque fichier. Si le fichier n'existe pas, un cercle blanc avec l'acronyme du partenaire est affiché à la place — donc tu peux remplir progressivement.

## Conseils

- **SVG** est largement préférable : net à toute taille, léger.
- Si **PNG**, fond **transparent**, taille minimum 256×256, idéalement 512×512.
- Pour un rendu uniforme dans le bandeau, recadre légèrement les logos très étirés (logos texte longs) en gardant le ratio carré.
- Compresse les PNG via [tinypng.com](https://tinypng.com) avant de commiter.

## Droits

Vérifie systématiquement les conditions d'utilisation des logos — la plupart des marques autorisent leur usage en partenariat sans modification, mais certaines requièrent une autorisation écrite. Pour les universités sénégalaises et institutions publiques, l'usage dans le cadre d'un partenariat éducatif est généralement accepté.
